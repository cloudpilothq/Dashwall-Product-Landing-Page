MIXERDECODED WORDPRESS THEME — VERSION 1.0.2
Based on the uploaded Dashwall 1.0.1 source archive.

INSTALLATION
1. Back up your WordPress site and database.
2. Upload mixerdecoded-theme.zip via Appearance > Themes > Add New > Upload Theme.
3. Activate on staging first.
4. Create a WordPress Page and select “Premium Product Landing Page” under Page Attributes > Template.
5. Set the page title. Add the long-form product description in Gutenberg.
6. In “MixerDecoded Product Landing Page Settings”, add the hero headline, intro, hero image, optional YouTube/Vimeo demo video, CTA, up to four benefits, gallery, genuine review excerpt, optional manually verified price and purchase details.
7. Set a featured image as fallback if no hero image is selected.

DESIGN STRUCTURE
The template follows the supplied reference: hero with headline and product image; benefit strip; dedicated product description; product gallery; social proof; pricing/purchase CTA; related resources.

COLOURS
Gradient: #00c196 to #1b6da0; hover/link: #0e979b; background: #f6f7fa.

IMPORTANT
This theme package has been syntax-checked, but has not been activated in your specific WordPress environment. Test on staging, especially with active plugins, SEO plugins, caching, consent tools and any custom Dashwall modifications. Affiliate links entered as CTA destinations are output with rel="sponsored nofollow noopener". Use only genuine review evidence. Pricing is not automatically fetched; enter or link to verified current retailer information. Existing Dashwall files and internal text domain are retained to preserve compatibility.
